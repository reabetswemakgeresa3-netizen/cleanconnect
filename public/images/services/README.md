# Service tile images

Drop an image here named after the service id and the Home screen tile
will use it automatically (falls back to the emoji if the file is missing).

Accepted extensions, checked in this order: `.webp`, `.jpg`, `.png`

| File name               | Tile              |
| ----------------------- | ----------------- |
| `residential.webp`      | Home Clean        |
| `office.webp`           | Office            |
| `industrial.webp`       | Industrial        |
| `gardening.webp`        | Garden            |
| `medical.webp`          | Medical           |
| `carpet.webp`           | Carpet            |
| `postConstruction.webp` | Post-Construction |
| `event.webp`            | Events            |

Recommended: square-ish images with transparent background (Uber-style 3D
renders work great), ~200×200px, kept under ~20 KB each.
